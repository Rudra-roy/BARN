①
B-Spline Path Smoothing
Converts jagged A* waypoints into a C²-continuous curve away from obstacles
Mathematical Model
Uniform Cubic B-Spline (C² continuous)
Segment $j$, parameter $t \in [0,1)$: $$C(t) = \frac{1}{6}\begin{bmatrix}1\!-\!3t\!+\!3t^2\!-\!t^3\\4\!-\!6t^2\!+\!3t^3\\1\!+\!3t\!+\!3t^2\!-\!3t^3\\t^3\end{bmatrix}^{\!\top}\!\!\begin{bmatrix}P_j\\P_{j+1}\\P_{j+2}\\P_{j+3}\end{bmatrix}$$
Curvature: $\kappa = \dfrac{|\dot{x}\ddot{y}-\dot{y}\ddot{x}|}{(\dot{x}^2+\dot{y}^2)^{3/2}} \;\le\; \kappa_{\max}=\dfrac{2}{W}$

Gradient descent cost: $$J = \underbrace{w_s\|P_{i-1}\!-2P_i\!+P_{i+1}\|^2}_{\text{smooth}} + \underbrace{w_a\|P_i-P_i^0\|^2}_{\text{anchor}} + \underbrace{w_o(d_{\text{clear}}-d)^2}_{\text{obstacle}} + \underbrace{w_c(\kappa-\kappa_{\max})^2}_{\text{curvature}}$$

  // Smoothness: penalise 2nd differences
  grad[i].x += params_.spline_smooth_weight * (-4.0 * ddx);
  grad[i].x += params_.spline_anchor_weight * 2.0 * (cp[i].x - anchor[i].x);
  // Obstacle push via distance field gradient
  const double push = params_.spline_obstacle_weight
    * (params_.desired_clearance - clearance);
  // Curvature: flatten if κ > κ_max = 2/W
  const double kappa_max = 2.0 / params_.track_width;
}
②
TOPP-RA Velocity Profiling
Time-optimal speed profile from wheel motor limits and curvature
Mathematical Model
Let $x(s) = \dot{s}^2$ (squared path velocity).

Wheel velocities (diff-drive, track width $W$): $$v_L = \dot{s}\!\left(1 - \tfrac{W}{2}\kappa\right),\quad v_R = \dot{s}\!\left(1 + \tfrac{W}{2}\kappa\right) \;\le\; v_{\text{wheel}}$$
Velocity ceiling at each $s$: $$x_{\max}(s) = \left(\frac{v_{\text{wheel}}}{\max(|1\!\pm\!\tfrac{W}{2}\kappa|)}\right)^{\!2},\quad x_{\max} \le v_{\text{max}}^2$$
Wheel accel: $$a_L = \frac{dx/ds\cdot(1\!-\!\tfrac{W}{2}\kappa)}{2} - x\tfrac{W}{2}\tfrac{d\kappa}{ds} \;\in\; [-a_{\text{max}}, a_{\text{max}}]$$
Reachability passes:
 • Backward: $x^b[i] = \min(x_{\max}[i],\;x^b[i\!+\!1] - u_{\min}\!\cdot\!ds)$
 • Forward: $x^f[i] = \min(x_{\max}[i],\;x^b[i],\;x^f[i\!-\!1] + u_{\max}\!\cdot\!ds)$
 • Output: $\dot{s}(s) = \sqrt{x^f(s)}$

// Step 1: velocity ceiling x_max(s) = ṡ_max²
double sdot_max = max_factor > 1e-9
  ? params_.wheel_v_max / max_factor
  : params_.max_speed;
sdot_max = std::min(sdot_max, params_.max_speed);

// Step 2: Backward pass
for (int i = n-2; i >= 0; --i) {
  xi = x_bwd[i+1] - u_min * ds;
  x_bwd[i] = std::clamp(xi, 0.0, x_max[i]);
}
// Step 3: Forward pass
for (int i = 1; i < n; ++i) {
  xi = x_fwd[i-1] + u_max * ds;
  x_fwd[i] = std::min({xi, x_max[i], x_bwd[i]});
}
// Convert ṡ = √x
sdot[i] = std::sqrt(std::max(0.0, x_fwd[i]));

Model Predictive Control (MPC)
Tracks the TOPP-RA trajectory over a prediction horizon, outputs cmd_vel
Mathematical Model
State: $\mathbf{x}_k = [x,\;y,\;\theta,\;v,\;\omega]^\top$   Input: $\mathbf{u}_k = [a,\;\dot\omega]^\top$

QP Cost over horizon $N$: $$\min_{\mathbf{x},\mathbf{u}} \sum_{k=0}^{N} \Bigl[Q_p\|e_{xy}\|^2 + Q_\theta e_\theta^2 + Q_v(v_k-v_{\text{ref},k})^2\Bigr] + \sum_{k=0}^{N-1}\Bigl[R_a a_k^2 + R_\omega \dot\omega_k^2 + S\|\Delta\mathbf{u}_k\|^2\Bigr]$$
Constraints: $$0 \le v_k \le v_{\max},\quad |\omega_k| \le \omega_{\max}$$ $$|a_k| \le a_{\max},\quad |\Delta v_k| \le \dot{v}_{\max}\cdot\Delta t$$
Obstacle avoidance (linearized half-plane): $$\nabla D(\mathbf{p})^\top (\mathbf{p}_k - \mathbf{p}_0) \ge d_{\text{obs}} - D(\mathbf{p}_0)$$
